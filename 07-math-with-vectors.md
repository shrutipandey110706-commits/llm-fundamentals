# With Vectors We Can Do Math

**Learning Resource:** Phillip Lacner — LLM Fundamentals

## 1. What Is a Vector?

A vector is an ordered list of numerical values.

For example:

`A = [1, 2]`

`B = [3, 4]`

In LLMs, embedding vectors represent tokens using learned numerical values.

## 2. Mathematical Operations on Vectors

Vectors can be used in mathematical operations such as addition, subtraction, and multiplication.

### Vector Addition

Suppose:

`A = [1, 2]`

`B = [3, 4]'


We add the corresponding elements:

`A + B = [1 + 3, 2 + 4]`

Result:

`A + B = [4, 6]`

Both vectors must have compatible dimensions for element-wise addition.

## 3. Why Is This Useful in LLMs?

LLMs perform mathematical operations on vectors and matrices to process information.

For example:

- Vector and matrix operations transform numerical representations.
- Learned weights influence how information is processed.
- Attention calculations help the model represent relationships between tokens.
- Neural-network layers transform representations as they pass through the model.

These calculations help the model learn and use patterns in language.

## 4. Important Point

An LLM does not simply add all token embeddings together to understand a sentence. Transformer-based LLMs use attention mechanisms and multiple neural-network layers to process contextual information.

## 5. Key Takeaways

- Vectors contain numerical values.
- Mathematical operations can be performed on vectors.
- Vector and matrix operations are fundamental to neural networks.
- LLMs use these operations to transform and process information.
