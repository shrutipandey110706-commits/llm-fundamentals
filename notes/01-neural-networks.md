# Neural Networks

**Learning Resource:** Phillip Lacner — LLM Fundamentals

## 1. What Is a Neural Network?

A neural network is a machine learning model that learns patterns from data. It consists of interconnected units called neurons, arranged in layers.

### Main Layers

- **Input Layer:** Receives input data.
- **Hidden Layers:** Process information and learn patterns.
- **Output Layer:** Produces the final prediction or result.

## 2. What Are Weights?

Weights are numerical values associated with connections in a neural network. They determine how strongly one part of the network influences another.

During training, the network adjusts its weights to improve its predictions.

## 3. How Does a Neural Network Learn?

Consider a cat-versus-dog classification example.

1. The model receives images labeled as cats or dogs.
2. Images are represented as numerical pixel values.
3. The network processes these values through its layers.
4. It generates a prediction.
5. The prediction is compared with the correct label.
6. During training, the weights are adjusted to reduce prediction errors.

After learning from many examples, the network can identify patterns that help it classify new images.

## 4. Neural Networks as Mathematical Functions

A neural network can be viewed as a complex mathematical function that maps numerical inputs to outputs.

For example:
- Images are represented using numerical pixel values.
- Text is converted into numerical representations.
- The network processes these representations to generate predictions or outputs.

## 5. Connection to LLMs

Large Language Models (LLMs) are based on neural networks. Most modern LLMs use the Transformer architecture to process sequences of tokens and learn relationships between them.

Neural networks are also used in image recognition, speech processing, and many other AI applications.

## 6. Key Takeaways

- Neural networks consist of input, hidden, and output layers.
- Neurons process information, while weights influence connections.
- Training adjusts weights to help the model learn patterns.
- Data such as images and text must be represented numerically.
- Neural networks form the foundation of modern LLMs and many other AI systems.
